# 情境卡格式（situations）

一张卡 = 一个具体到能对号入座的情境。**卡片给方向和要素，不给标准答案。**
最终回复永远由模型按对方画像、你们的关系阶段、你自己的说话习惯重新写成一句话。

数据按场景分文件存放，一个场景一个文件，这样众包提 PR 不会互相冲突：

```
data/scenes/daily.jsonl        分享日常
data/scenes/period.jsonl       生理期
data/scenes/conflict.jsonl     闹矛盾 / 被冤 / 双方的摩擦
data/scenes/jealousy.jsonl     吃醋
data/scenes/latenight.jsonl    深夜情绪
data/scenes/meetup.jsonl       从聊天到约出来
data/scenes/family.jsonl       家人与家庭
data/scenes/distance.jsonl     异地
data/scenes/friends.jsonl      朋友与社交
data/scenes/anniversary.jsonl  生日与纪念日

data/threads/<scene>.jsonl     多轮链，场景同上
data/openers.jsonl             开场白，全场景共用一个文件
```

每行一个 JSON 对象，UTF-8 无 BOM，字段如下。

## 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | `前缀-三位序号`，前缀必须等于文件名。如 `daily-001` |
| `scene` | string | 是 | 必须等于文件名去掉 `.jsonl` |
| `title` | string | 是 | 6–14 字，人话概括这个情境 |
| `signal` | string | 是 | 对方到底说了什么、做了什么。越具体越好，写成一句可复现的现场 |
| `stage` | string[] | 是 | 关系阶段，取值：`初识` `聊得来` `暧昧` `已在恋爱` |
| `goal` | string | 是 | 这一次要达成什么：接情绪 / 推进 / 降级 / 给出口 |
| `moves` | string[] | 是 | 2–4 个，取值见《手法》 |
| `examples` | object[] | 是 | 2–3 条，每条 `{style, text}`，`style` 取值见《风格》 |
| `taboo` | string[] | 是 | 2–3 条，写到「别说什么」的具体句子 |
| `followup` | string | 是 | 对方冷淡、已读不回、隔天才回时的续法 |
| `tags` | string[] | 是 | 2–5 个检索词。写用户会搜的词，不写抽象词 |
| `difficulty` | int | 是 | 1 日常轻量 / 2 要判断情绪 / 3 高危（冲突、吃醋、危机） |

## 手法 moves

`共情` `站队` `抛小问题` `自嘲` `玩梗` `认真回应` `转移话题` `给出口` `推进` `退让`

## 风格 style

`共情` `玩梗` `认真` `自嘲` `反向好奇` `推进` `退让`

## 写卡的口径

1. **示例是微信原话**，不是理念。一条不超过 40 个汉字，读出来要像真人会发的。
2. **不许出现称呼**（宝、宝宝、小仙女、亲爱的）。需要称呼时写 `{称呼}`。
3. **不写土味情话，不写油腻夸赞**。夸也要夸具体的事。
4. **不写单独的「哈哈哈」**。单独哈哈哈放 `taboo` 里当反面教材。
5. **不用书面语连接词**（其实我觉得、某种程度上、总而言之）。
6. **一张卡只解决一个情境**。如果 signal 里出现了两种状况，拆成两张。
7. **taboo 要具体到句子**。写「别说那你别吃了」，不要写「避免否定对方情绪」。
8. **followup 必须是真的可执行**，比如「十分钟后拍张自己的晚饭发过去，不解释刚才」，不要写「保持沟通」。

## 红线（写卡时必须遵守）

- 不写打压、冷处理、假装忙、欲擒故纵、试探性欺骗、性暗示。
- 不涉及未成年人。
- 对方已明确拒绝后，不提供继续纠缠的话术；这类只能给「体面退场」。
- 深夜情绪场景遇到极端消极表述，卡片必须指向专业资源或身边可信任的人，不许用玩梗盖过去。
- 生理期场景，`多喝热水`、`忍一忍`、`吃药就好了` 一律只能出现在 `taboo`。

## 自检

写完在仓库根目录跑：

```bash
python scripts/lint_data.py       # 情境卡与多轮链
python scripts/lint_extra.py      # 多轮链与开场白
python scripts/eval.py            # 检索回归，改了检索参数才需要跑
```

字段缺、id 重、风格不在枚举、示例超长、命中红线词，都会报错并定位到行号。

# 多轮链格式（threads）

一张卡解决「这一条怎么回」，一条链解决「接下来三轮怎么走」。用户真正卡住的地方，多数在第二句之后。

每场景 5 到 7 条，一场景一个文件。字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | `th-<场景>-两位序号`，如 `th-daily-03` |
| `scene` | string | 是 | 同情境卡的场景枚举 |
| `title` | string | 是 | 4–20 字，写清这条链在解决什么 |
| `premise` | string | 是 | 10–80 字，交代关系阶段和当时的状况 |
| `turns` | object[] | 是 | 3–5 轮，每轮 `{her, you, why}` |
| `exit` | string | 是 | 6–80 字，怎么收尾、她没接时停在哪 |
| `tags` | string[] | 是 | 2–5 个检索词 |
| `difficulty` | int | 是 | 同情境卡 |

`turns` 里的 `her` 是她说的话（2–60 字），`you` 是你的回应（4–60 字），`why` 是这一句为什么这么走（4–30 字，写给写卡人和模型看，不发给对方）。

写链的额外口径：

1. **轮与轮之间要有变化**。第二轮的回应不能和第一轮同一个动作，否则就是复读。
2. **每一轮都要推进一小步**：从情绪到具体的事，从具体的事到一个动作，从一个动作到时间地点。
3. **`exit` 必须写「她没接怎么收」**。这是这套数据最有用的地方，比怎么回更值钱。
4. **危机链优先**。`latenight` 里出现极端表述的链，必须指向专业资源或身边可信任的人，不许用玩笑收尾。

# 开场白格式（openers）

用户「想聊但没由头」时用。全部放在 `data/openers.jsonl`，一个文件，因为跨场景复用。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | `op-三位序号` |
| `scene` | string | 是 | 最贴合的场景 |
| `stage` | string[] | 是 | 适合的关系阶段，可多选 |
| `anchor` | string | 是 | 由头类型：`共同经历` `她提过的事` `当下时空` `轻话题` `求助请教` |
| `title` | string | 是 | 4–20 字 |
| `example` | string | 是 | 4–60 字，可以直接发的一句 |
| `why` | string | 是 | 6–60 字，她为什么接得住 |
| `followup` | string | 是 | 6–60 字，她接了之后往哪走 |
| `tags` | string[] | 是 | 2–5 个 |
| `difficulty` | int | 是 | 1 或 2，开场白不用 3 |

写开场白的口径：

1. **`她提过的事` 排第一优先**。她说过的事你记得，比任何新话题都好接，也不显得刻意。
2. **`当下时空` 只在还热的时候用**。她三天没回，再用天气和地铁，就像在硬找话说。
3. **一句里最多一个问号**，最好零个。开口是给由头，不是查户口。
4. **不许复述她的原话当开场**，那显得你没别的话可说。

## 链与开场白的示例

```json
{"id":"th-daily-03","scene":"daily","title":"她主动问在干嘛","premise":"暧昧期，你们平时两三天聊一次，今天她先发消息","turns":[{"her":"在干嘛","you":"刚把碗洗完，正想着晚上干点什么","why":"给一个具体画面，留话头"},{"her":"这么乖，还洗碗","you":"我妈说我再不洗就没饭吃。你呢，今天怎么这么闲","why":"自嘲一下，把话递回去"},{"her":"我也是刚忙完，躺着刷手机","you":"躺着刷手机最费时间。要不要换个姿势，走两步去楼下买杯东西","why":"从闲聊引到一个动作"},{"her":"这么晚还出去啊","you":"那就明天，下班那会儿我去你公司附近，十分钟的事","why":"把动作落到明天"}],"exit":"她答应就定时间；她说再说吧就到这儿，第二天别再提，隔两天聊别的","tags":["在干嘛","主动","约","接话"],"difficulty":1}
```
