# 样例：她在吐槽食堂

完整走一遍，看看它输出什么、为什么这么回。

## 用户输入

> 她发了张食堂菜的照片，说「又是这个，我快吃吐了」，我该回啥

## 第一步：读画像

```bash
python scripts/profile.py show 小鹿
```

```
【小鹿】
关系阶段: 暧昧
MBTI: INFP
星座: 双鱼
作息: 凌晨一点后在线，早上不回消息
饮食: 不吃香菜，爱辣，奶茶三分糖
在意的事: 十二月的教资面试
雷区: 讨厌被追问「怎么不回我」
近期事件: 上周和室友因为卫生吵过一次
```

## 第二步：检索

```bash
python scripts/query.py "又是这个，我快吃吐了"
```

命中下面这张卡（节选）：

```
[1] daily-001  食堂饭难吃   难度1  阶段:聊得来/暧昧
    现场: 她发一张食堂菜的照片，配一句「又是这个，我快吃吐了」
    目标: 接住情绪，别急着给方案
    手法: 共情 / 站队 / 抛小问题
    示例:
      - 共情  这菜看着确实像在惩罚吃饭的人
      - 玩梗  食堂大师傅是不是跟你有什么旧账
      - 反向好奇  你今天原本想吃什么，我给你记着
    别说: 讲营养均衡；说那你别吃了；只回哈哈哈
    续法: 她只回一个表情的话，过二十分钟拍自己那份饭发过去
```

## 第三步：输出

```
【判断】她这条是想被接住一下，顺便吐槽，不需要你评理，也不要你给方案。

【可以这样回】
1. 稳一点：这看着确实像在惩罚人，你连着吃几天了
2. 轻一点：食堂这是跟你结了多大的仇
3. 试一下：今天是不是又被香菜坑了，我记着你不吃那个

【别这样回】
- 「少吃点油，注意营养」：她要的是站在她这边，不是体检报告。
- 「那你别吃了」：听起来像让她自己解决。

【她要是只回一个表情，你就过二十分钟拍自己那份饭发过去，配一句「我这也不相上下」】
```

## 为什么这么改

- 第一条把「像在惩罚人」换成更口语的说法，加了「连着吃几天了」这个具体追问，比卡片示例多一个话头。
- 第三条用了画像里的「不吃香菜」，这是卡片里没有的信息，也是对方看到会笑的地方。
- 没有用梗：`玩梗` 那条容易显得在抢戏，而她刚在抱怨，需要先被接住。
- 三条都不超过二十个字。她的话很短，回长了会显得用力。

## 反面样例

如果照抄卡片第一条，发出去是「这菜看着确实像在惩罚吃饭的人」。没错，但它是一次性回答，对话会停在那儿。卡片给的是方向，多出来的「连着吃几天了」才是让话能接下去的东西，这一步只能由模型按现场补。
