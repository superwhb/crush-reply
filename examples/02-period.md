# 样例：她说肚子疼得厉害

这个场景最容易翻车，因为它同时考三件事：判断严重程度、给具体动作、别把关心做成医嘱。

## 用户输入

> 晚上八点她说「疼得厉害了，坐着都难受」，隔了很久才补一句「刚趴了一会儿」

## 第一步：读画像

```
【小鹿】
关系阶段: 暧昧
饮食: 不吃香菜，爱辣，奶茶三分糖
雷区: 讨厌被追问「怎么不回我」
近期事件: 上周说这周期末周，连着几天早八
```

画像里已经有一条关键信息：她这周在考试周，所以「躺着休息」对她不是无成本的选项。

## 第二步：检索

```bash
python scripts/query.py --scene period "疼得厉害了，坐着都难受"
```

```
[1] period-003  说肚子疼得厉害   难度2  阶段:聊得来/暧昧/已在恋爱
    现场: 晚上八点她说「疼得厉害了，坐着都难受」，隔了很久才补一句「刚趴了一会儿」
    目标: 认真接住疼，落到一个具体动作
    手法: 共情 / 认真回应 / 推进
    示例:
      - 共情  这句听着就知道不是一般的疼
      - 认真  你现在一个人在家还是有人陪，我想知道该不该过去
      - 推进  我给你点份热的汤，二十分钟到楼下
    别说: 忍一忍就过去了；是不是吃坏东西了；吃点止痛药吧
    续法: 她没回先不追，一小时后发「汤点了，放门口，你拿了再说一声」
```

## 第三步：输出

```
【判断】她是在说疼，不是在问怎么办。这条要接住疼痛，再落一个能立刻执行的动作。

【可以这样回】
1. 稳一点：坐着都难受那挺严重了，你现在一个人在家吗
2. 带点具体的：我点份热汤给你，二十分钟到，别下来接
3. 只在她回得慢时用：你先趴着，不用回我，睡醒再说

【别这样回】
- 「多喝热水」「忍一忍就过去了」：她听过一百遍了，等于没说。
- 「是不是吃坏东西了」：这是在找原因，她要的是有人管。
- 「去吃点止痛药吧」：给药建议越界，而且她可能已经吃了。

【她要是半小时没回，一小时后补一句「汤放门口了，你拿了再说一声」，然后别再发】
```

## 为什么这么改

- 删掉了卡片里那句「我想知道该不该过去」。在暧昧期直接问「要不要我过去」会把决定权丢给她，而她正疼着。改成「你一个人在家吗」是同一个信息，但压力小。
- 加了「别下来接」，因为画像里她连着早八，能省一步是一步。
- 三条按她回复速度分层给，不是三个平行选项。这是这个 skill 和普通话术库的区别：它想象了对话走向。

## 反面样例

「多喝热水」之所以被全网当梗，不是因为水没用，是因为它把关心变成了一个零成本的句子。卡片把这类话放在 `taboo` 里，就是强制模型去想：我能做的那件具体的事是什么。
