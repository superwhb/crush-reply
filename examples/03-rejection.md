# 样例：她说不合适

这个样例专门演示「不追」。项目在这一点上没有折中方案。

## 用户输入

> 她说「我觉得我们还是做朋友比较好，我对你没有那种感觉」，还能挽回吗

## 第一步：检索

```bash
python scripts/query.py --scene meetup "还是做朋友比较好，我对你没有那种感觉"
```

```
[1] meetup-007  她明确说不合适   难度3  阶段:聊得来/暧昧
    现场: 她说「我觉得我们还是做朋友比较好，我对你没有那种感觉」
    目标: 体面退场，把话收干净
    手法: 退让 / 给出口
    示例:
      - 退让  明白了，谢谢你直接说，省得我猜
      - 退让  那就做朋友，之前约你的事当我没提
      - 退让  祝你碰到合适的人，我这边也会好好的
    别说: 问「为什么」或者「我哪里不好」；改约别的时间来试探，三次以上就成纠缠；说「我等你想通」
    续法: 之后别再单独发消息；她要聊就正常聊，不提这件事，也不发深夜长文
```

## 第二步：输出

```
【判断】这是明确的拒绝，不是考验。她说得很清楚，不需要你再确认一遍。

【可以这样回】
1. 只发一句：明白了，谢谢你直接说，省得我猜
2. 想留个体面：那就做朋友，之前约你的事当我没提

【别这样回】
- 「为什么，我哪里不好」：她刚给了答案，再问就是让她为难。
- 「那我等你」：把等待变成她的负担。
- 「好吧，那以后再说」：留一条尾巴，两个人都没法真的翻篇。

【发完这一句就停。之后她要聊就正常聊，不提这件事，也不发深夜长文】
```

## 为什么不做「挽回策略」

因为在这份数据里，明确拒绝之后的卡片只有退让。项目在 `SKILL.md` 和 `scripts/lint_data.py` 里都写死了这条：不提供纠缠话术，包括改期、制造偶遇、让朋友递话、隔一段时间再问一次。

你可以不同意这个立场，去改源码，但改完 CI 会拦你。这就是把底线写进代码而不是写进口号的意思。

## 顺便说一句

如果用户问「还能挽回吗」，正确的回答是先说清这是拒绝，再问他现在需不需要聊点别的。不要给概率，不要说「还有机会」，那是拿他的期待换一个好看的回答。
