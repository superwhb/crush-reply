# 样例：第二句之后才是真问题

这个样例不用卡片，用多轮链。因为用户真正的失败点很少在第一句：第一句他们大概知道该说什么，难的是她回了个「嗯」之后。

## 用户输入

> 她说想辞职，我说了几句她就不说话了

## 第一步：读画像

```
【小鹿】
关系阶段: 暧昧
作息: 每天六点半起，十一点前睡
雷区: 不喜欢被安排，讨厌「你应该」
近期事件: 连着加班两周，方案改到第四版
```

两条都指向同一件事：她现在是耗竭状态，不是需要方案的状态。画像里「讨厌被安排」也排除了所有给建议的开场。

## 第二步：检索多轮链

```bash
python scripts/thread.py --scene daily "她说想辞职，说完就不说话了"
```

```
[1] th-daily-05  她说想辞职   难度2
    前提: 暧昧期，她工作半年，最近连着加班，情绪一直在往下走
    走向:
      1. 她: 我今天真的想辞职
         你: 今天又发生什么了   (先问具体的事，不急着劝)
      2. 她: 方案改了四版，领导还说不行
         你: 四版还不满意，这不太像你的问题   (站队，但不替她下结论)
      3. 她: 我也不知道，可能我确实不行
         你: 你先别急着给自己下判词。今晚想不想吃点什么，我点   (把她从自我否定里拉出来)
      4. 她: 吃不下
         你: 那就不吃，喝点热的。明天要是还想辞，我们再认真算一下钱的事   (给延后处理的出口)
    收尾: 今晚只陪，不分析职业规划；她第二天情绪好了会自己提，别追着问
```

## 第三步：输出

```
【判断】她说辞职是在卸力，不是在征求建议。上一轮她不说话，不是不想聊，是你说的话让她觉得还得再解释一遍。

【可以这样回】
1. 稳一点：今天又发生什么了
2. 轻一点：这么改下去人是会被磨没的，你不算矫情
3. 再往下半步：今晚别想辞职的事，想不想吃点什么，我点

【别这样回】
- 「要不你先忍忍，年底再说」：她要的是被承认难受，不是职业规划。
- 「辞职之前先想好下一份」：这是把她的话当成一个待办事项在回应。
- 「我也天天想辞职」：抢走她的情绪，话题就变成你的了。

【她要是只回一个表情，你就】不追，隔两小时发「汤到了，放门口」，别问「在吗」。

【第二三轮注意】第三轮最容易崩。她会开始自我否定（「可能我确实不行」），这时候你一旦开始举例子证明她行，就会变成辩论。这一段只做两件事：把「一件错事」和「你这个人」拆开，然后给一个当晚能做完的小动作。
```

## 为什么这么改

- 第 3 轮那句「你先别急着给自己下判词」是整条链的转折点。换成「你其实挺厉害的」就变成评价她，她会接着举反例，对话立刻死。
- 第 4 轮给的是延后处理的出口（明天再算钱），不是解决。今晚解决不了她的工作，但能解决她的今晚。
- 收尾那句「她第二天情绪好了会自己提，别追着问」比任何一句回复都值钱：多问一句，前面三轮白做。

## 这张链教会的事

单卡能告诉你「第一句别说多喝热水」，只有链能告诉你「第三句别说你很优秀」。前者是常识，后者是经验。仓库里 107 条链，基本都是后半句。
