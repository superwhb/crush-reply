# 样例：库里没有这张卡

这份样例演示第三步半：先确认库里真的没有，再去外面找结构，最后按 `voices/` 写成一句能发的话。

## 现场

> 她说「你根本不懂我在气什么」，我确实不知道。我们才认识一个多月。

```
【小鹿】
关系阶段: 聊得来
认识多久: 一个多月
在意的事: 下个月的转正答辩
雷区: 被追问「你到底在气什么」
```

她没讲发生了什么事，只下了一个判断：你不懂。我的第一反应是「那你告诉我啊」，但这句话在一个多月的关系里像在要证据，她会更不想说。

三张卡都只是擦边。第一张是她讲过、我没听；第二张要的是「已在恋爱」，我们没有那个积累；第三张是她对旁人失望，不是对我不懂。没有一张是「她生气了，而我确实不知道原因」，分数排得出来，情境对不上。

## 算检索词

```bash
python scripts/find.py "她说你根本不懂我在气什么"
```

```

猜测场景：没判断出来（-）

## 检索词（按顺序搜，够用就停，别把六条都搜一遍）

2. `"你根本不懂我在气什么" 高情商回复`

   小红书的对话截图和评论区，语境最近

## 搜到之后怎么提炼

只抄情境结构，不抄句子。四行就够：
- 她的原话里，真正在要的是什么（被接住 / 被认同 / 要空间 / 想推进）
- 网上那些回复里，共同的动作是什么（先接情绪，还是先给方案）
- 哪一种做法在你这个阶段不成立，为什么
- 你会用的一句：用 voices/<代号>.md 里的句式和标点重写，不要用网上的原句
```

它连场景都没猜出来，说明这句话不落在库里任何一类。检索词全是她的原话加引号，因为整句里没有一个库内标签。提炼模板只要四行，别把六条检索词都搜一遍，前两条够用。

## 外部参考

用前两条检索词搜了小红书和知乎，评论区里反复出现同一个结构：先不解释「我不是那个意思」，而是问她自己怎么看这件事；等她说完，再说自己看到的那一版；不猜她的动机，也不替她总结。共同的动作是把解释权还给她。这里写的是从多个帖子里提炼出来的结构，不是任何一条原帖的句子，也没有引用账号或链接。

## 写法对照

- **套话**：「别生气了，我以后注意。」错在跳过了「不知道」，她听到的是你连她气什么都没问就想过关。
- **照网上抄**：「我们先冷静一下，等你想说的时候再说。」这是别人关系里的台词，抄过来是通用动作；一个多月说「冷静一下」，像在推开她。
- **按 voices 写**：「我没听懂你气的是哪件事，你讲给我听，我不猜。」承认不知道，给她一个能接的动作；句式照 `voices/<代号>.md`，一句话说完，句号收尾。

## 收尾

回答里要先说：这个情况库里没有这张卡，下面是按公开讨论里反复出现的结构给的，不是查表查到的。
然后建议补卡，用 `python scripts/find.py "她的原话" --note` 记进 `research/gaps/`，同一类攒到三次就按 `data/schema.md` 补一张。
不能拿「通常女生都……」糊过去：那是把她的具体情绪换成一个类别，用户会照着类别去猜，下一次还是不知道她在气什么，还会让她觉得这次也没被听懂。
